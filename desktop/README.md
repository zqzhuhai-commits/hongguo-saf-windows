# 红果短剧SAF版 0.8.0

## 使用

适用于 Windows 10 / 11 64 位（x64）。双击
`红果短剧SAF版-0.8.0-Windows-x64.exe` 即可启动；首次启动会解包运行环境，稍等片刻。
无需安卓模拟器、Java、Node.js、Docker 或部署外部服务。观看内容需要联网。
如果使用 ZIP 版本，先完整解压，再双击文件夹中的 `红果短剧SAF版.exe`，不要单独移动它。

此文件是便携启动 EXE，应用设置和观看记录仍保存在当前 Windows 用户的应用数据目录，
不会随 EXE 移动到另一台电脑。设置中可以导出与导入片单备份。

## 功能

- 漫剧 / 短剧推荐、漫剧热播榜、关键词搜索与分页。
- 剧集详情、集数跳转、选集、上下集、自动连播。
- 原比例播放、暂停、进度拖动、全屏、10 秒跳转、倍速及清晰度偏好。
- 收藏、稍后看、最近观看、按分集 ID 断点续播。
- 分钟 / 集数定时停止；支持导入原 Kotlin 安卓版 JSON 片单备份。
- 本地 JSON 备份导出与合并恢复，保留较新的观看进度。

空格播放 / 暂停，左右方向键跳转 10 秒，Esc 返回，F11 全屏。
清晰度优先采用兼容的 AVC / H.264；来源只有 HEVC 时，兼容性取决于 Windows 的解码能力。
视频只在内存中分段处理，不提供整部剧下载功能。

## 与安卓版的差异

本版重新制作鼠标 / 键盘界面，不保留电视遥控器焦点布局。
未实现手机二维码输入、手机局域网备份、收藏更新检查、推荐隐藏、后台账号同步或应用内自动更新。
JSON 备份可手动导入；没有实现红果账号登录或账号同步。
导入的「已看」「隐藏」字段可保存在备份中，桌面界面暂不提供相应编辑入口。

## 验证说明

交付包生成了 Windows x64 可执行文件及便携包装器。
17 项自动检查覆盖媒体 Range / HEAD、请求隔离、SM3 兼容、榜单解析、AVC 编码标识、
片单保存重启、备份合并和 DOM 界面流程。核心 10 项也在 Electron 内置 Node 运行时通过。
界面测试使用明确标记的夹具和模拟媒体事件，不构成视频解码验收；夹具不会进入发布版。

当前构建环境无法在 Windows 实机运行。内容源联网检查结果见源码包中的
`verification.json`；环境网络限制导致内容源请求失败时，不能据此声称真实剧集已经播放验收。
目标 Windows 上的真实播放、硬件解码和长期运行仍需验证。

## 从源码构建

安装 Node.js 22 或以上，在 desktop 目录运行：

```sh
npm ci
npm test
npm start
npm run build:win
```

输出位于仓库根目录 `outputs/windows/`。Electron 44.7.0、electron-builder 26.15.3
及依赖版本由 package-lock.json 固定。构建会下载 Electron 和 NSIS 工具，需联网。
发布 EXE 未配置 Authenticode 签名。

真实内容探测：`node probe.mjs verification.json`。探测失败会返回非零退出码。

对应源码以 GPL-3.0-only 提供，来源、提交与第三方声明见 NOTICE.md、LICENSE 和 vendor/。

应用名称已统一为「红果短剧SAF版」，保留旧版数据目录，原本机收藏和观看记录可继续使用。
